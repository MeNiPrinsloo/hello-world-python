
# Hello, World! 🐍

My first Python project as a Software Engineering student at Western Governors University (WGU).

## About This Project
A beginner-friendly interactive Python program that welcomes users, asks for their name, and displays a personalized greeting.

## What I Learned
- Using `print()` to display messages
- Using `input()` to collect user input
- Creating and using variables
- Combining strings with the `+` operator
- Running Python programs in Visual Studio Code

## How to Run
1. Make sure Python 3 is installed.
2. Download the `hello_world.py` file.
3. Open a terminal in the file's folder.
4. Run the following command:

    python hello_world.py

5. Enter your name when prompted!
